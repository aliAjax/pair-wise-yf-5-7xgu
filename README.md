# 社区共享厨房 · 保鲜柜预约

纯本地网页应用：住户在手机浏览器里预约保鲜柜格子、取餐时凭管理员发放的六位码核销；系统自动处理超时释放，管理员可查看全部记录。无需安装、无需服务器、无外部依赖，数据保存在浏览器本地（localStorage）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构（预约 / 取餐 / 管理 三个标签页） |
| `styles.css` | 手机优先的响应式样式 |
| `app.js` | 全部业务逻辑与本地数据读写 |
| `smoke-test.js` | Node 业务规则冒烟测试（不影响应用运行） |

## 如何使用

### 本机打开

直接双击 `index.html`，或在目录下起一个静态服务：

```bash
python3 -m http.server 8000
# 手机与电脑连同一 Wi-Fi，用手机浏览器访问 http://<电脑IP>:8000
```

> 手机上长期使用时，可在浏览器菜单选择「添加到主屏幕」，像 App 一样打开。

### 住户操作（预约 / 取餐）

1. **预约**：打开页面填写「房号 + 姓名」，选择日期（未来 14 天内）、时段、冷藏/冷冻层和餐盒数量（每盒占 1 格，单次最多 6 盒）。
   - 白色 = 空闲，绿色 = 本次预选，橙色 = 已占用；
   - 点橙色格子可查看 **占用住户、结束时间、最晚核销时间**；
   - 已占用格子不可选，**新预约绝不会覆盖旧记录**。
2. 三个时段（格子在对应时段内独立占用）：
   - 上午 08:00–12:00 / 午间 12:00–18:00 / 晚间 18:00–22:00
3. 每户最多保留 **2 个未来有效预约**（已核销/已超时的不计入）。
4. **取餐**：向管理员索要六位取餐码 → 底部「取餐」标签输入六位码 → 核销成功，格子立即释放。

### 管理员操作

1. 底部「管理」标签，默认管理码 **`8888`**（登录后请在页面内修改）。
2. 对每条「待核销」记录可：
   - **生成/查看六位取餐码**：把码口头或微信发给住户；
   - **代客核销**：住户当面取餐时直接核销；
   - **删除记录**。
3. 顶部统计：当前占用预约、涉及住户数、超时释放记录、累计已核销。
4. 记录可按「全部 / 待核销 / 已核销 / 已超时」筛选；超时记录永久留存，只有管理员能删除。
5. 可调整冷藏/冷冻层格子数量（默认 12 / 10）。
6. **数据管理**：导出 JSON 备份、导入恢复、生成演示数据、清空数据。

### 超时规则

- 每个时段**结束时间 + 2 小时**为核销截止（如晚间时段最晚 24:00 前核销）。
- 到期未核销：记录自动变为「已超时」，占用格子**立即释放**给其他住户，记录保留在管理员列表。
- 系统每 30 秒扫描一次；打开页面、切换标签时也会立即扫描，无需人工处理。

## 数据与多设备说明

- 数据仅存在运行应用的那台设备的浏览器 localStorage 中，不上传任何服务器。
- 同一台电脑的多个浏览器标签会实时同步；**不同设备之间数据不自动共享**。
- 需要换机/多人管理时，用管理台的「导出数据」生成 JSON，在另一台设备「导入数据」即可搬迁。
- 清除浏览器数据会导致记录丢失，请定期导出备份。

## 测试

```bash
node smoke-test.js
```

覆盖：自动分格、占用不覆盖、两层独立计数、每户 2 个上限、容量不足拒绝、过期时段拒绝、六位码核销与防重复、超时自动释放且记录留存。

## 后续可扩展

- 用 PWA（manifest + service worker）支持离线添加到主屏；
- 换成一台常开设备（如物业电脑）作为“数据主机”，或接入轻量后端（JSON 文件 / SQLite）实现多设备实时共享；
- 预约成功后导出取餐二维码。
