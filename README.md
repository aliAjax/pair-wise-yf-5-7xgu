# 社区共享厨房 · 保鲜柜预约系统

零依赖 Node.js 小应用，数据存在本地 `data.json`，手机浏览器直接访问。

## 启动

```bash
node server.js                 # 默认 3000 端口
PORT=8080 ADMIN_KEY=自定义口令 node server.js
```

手机与服务器连同一 Wi-Fi，浏览器打开 `http://<服务器IP>:3000` 即可。默认管理员口令 `admin123`，务必用 `ADMIN_KEY` 环境变量改掉。

## 功能与规则

- **预约**：选日期（未来 7 天）、时段（早/午/晚）、冷藏或冷冻层，填餐盒数量（1–20）。
- **防覆盖**：同日期+时段+层只允许一条有效预约；被占用时页面和接口都会显示占用住户与结束时间，返回 409，绝不覆盖旧记录。
- **限额**：每户最多同时保留 2 个未来预约，超出返回 429。
- **核销**：预约成功生成六位码，取餐时住户出示，管理员在「管理员」页输入口令+码核销；重复核销、已释放的码都会被拒绝。
- **超时释放**：时段结束后 2 小时仍未核销，系统自动把格子释放（状态 `released`），记录保留在管理员列表可查。每次请求时即时清扫，另有每分钟兜底扫描。
- **管理员列表**：全部记录（进行中/已核销/超时释放/已取消）可按状态筛选，需口令访问。
- **住户取消**：在「我的预约」里可取消自己未核销的预约。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state?household=` | 7 天格子占用情况 + 该住户的预约 |
| POST | `/api/reservations` | 新建预约 `{household,date,slot,layer,boxCount}` |
| POST | `/api/redeem` | 核销 `{adminKey,code}` |
| POST | `/api/cancel` | 住户取消 `{id,household}` |
| GET | `/api/admin/records?adminKey=&status=` | 管理员总表 |

## 文件

- `server.js` — 服务与全部业务规则
- `public/index.html` — 手机端单页（预约 / 我的预约 / 管理员三个标签页）
- `data.json` — 本地数据（原子写入，勿手改）
